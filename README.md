# 🚀 3D Animated Portfolio - Mayank Paliwal

A visually immersive and interactive **personal portfolio website**, designed to showcase video editing projects, film works, and creative skills through a dynamic 3D experience.

---

## ⚙️ Core Technologies & Stack
- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- **Three.js & WebGL:** 3D scene rendering, lighting, and interactive spatial controls.
- **GSAP (GreenSock Animation Platform):** High-performance animation engine.
- **ScrollTrigger:** Seamless scroll-driven storytelling sequences.

---

## ✨ Key Features
- 🎞️ **Scroll-Based 3D Scenes:** Interactive 3D workspace model animating seamlessly on scroll.
- 🎬 **Featured Work Showcase:** Highlighting long-form podcast edits (Raj Shamani, BeerBiceps), viral short-form series (Daud), and freelance productions.
- 📱 **Responsive & Fast:** Optimized asset loading for fluid performance across desktop and mobile devices.
- 🎨 **Modern Cyber-Aesthetic:** Styled interface with audio controls, custom canvas rendering, and dark mode theme.
